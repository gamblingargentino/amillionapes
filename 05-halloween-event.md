# Halloween event

Halloween is 8 days from today (2026-10-31), so the event has to be a thin layer on top of the core game, not new systems.

## Must have

- Pumpkin-head skin on the ape and machine enemies (a model swap, no new behaviour).
- Hollow Harvest cornfield map ([maps](04-maps.md)).
- Candy drops from kills, spent in an event-only shop.
- Wave-13 boss: scarecrow. Defeating it unlocks an event title.

## Nice to have

- Wave mutators: lights go out, fog, a ghost wave you can only hurt with a flashlight beam.
- Trick or treat doors on the map: a trap (ambush wave) or a treat (health, cash, weapon).
- Day-night cycle that darkens each wave.
- Lobby decorations.

## Event shop ideas

Candy-corn shotgun skin, broom ultimate effect, pumpkin helmet cosmetic, event title.

## Cut list if time runs out

Cut in this order: lobby decorations, trick or treat doors, mutators, candy shop. Never cut the pumpkin skin or the boss.

## Technical rule

The event runs from a config value (start and end dates, skin set, shop list) so it can switch on and off without a code change.
