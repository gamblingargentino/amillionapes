# Roadmap

Today is 2026-10-23 and Halloween is 2026-10-31. Eight days is tight for two people, so the plan is a thin playable slice first, then the event layer. If the slice slips, ship the event as a short update after Halloween rather than cutting quality.

| Phase | Dates | Goal | Done when |
|---|---|---|---|
| 0. Setup | Oct 23-24 | Decisions and tooling | Name, repo, folder ownership and prompts agreed ([decisions](12-decisions-and-open-questions.md)) |
| 1. Playable core | Oct 24-27 | One greybox map, wave director, 3 enemy types, 2 weapons, cash upgrades, results screen | A squad of 2 can play 10 waves |
| 2. Event slice | Oct 27-30 | Pumpkin skins, Hollow Harvest map, candy shop, scarecrow boss | Full run to wave 13 works |
| 3. Release | Oct 30-31 | Playtest, fix crashes, performance pass, publish | Public build live |
| 4. After launch | Nov | Perk draft, hybrids, classes, Research Base zones | See [classes](03-classes-and-weapons.md) |

## Priorities inside each phase

1. The loop must be fun with grey boxes before any art.
2. Server performance with four players and a full wave.
3. Save data safety (gems, unlocks).
4. Polish last.

## Risks

- Scope: the perk draft and hybrids move to phase 4 if phase 1 slips.
- Roblox already has wave-survival clones, so differentiation matters (see [reference analysis](research/reference-game-analysis.md)).
- Rate limits on either Claude subscription (see [workflow](09-two-dev-workflow.md)).
